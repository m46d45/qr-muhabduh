# qr-muhabduh

Kartu QR [Muhamad Abduh](https://muhabduh.id). Arahkan kamera ponsel ke kode untuk membuka situs.

## Pengembangan

```bash
npm install
npm run dev
```

Buka [http://localhost:8080](http://localhost:8080).

```bash
npm run build
npm run preview
```

## Tumpukan

React 19, TanStack Start, Tailwind CSS v4. Deploy di Vercel.
